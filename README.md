# go-timer

A countdown timer with preset durations. Pure HTML/CSS/JS — open `index.html` directly in any browser, no server required.

## Presets

| Preset | Duration |
|--------|----------|
| S0 | 5:00 |
| S1 | 4:50 |
| S2 | 4:40 |
| S3 | 4:30 |
| S4 | 4:20 |
| S5 | 4:10 |
| S6 | 4:00 |
| S7 | 3:50 |
| S8 | 3:30 |
| S9 | 3:10 |
| S10 | 3:00 |

## Usage

Open `index.html` in a browser, pick a preset, press **Start**.

Keyboard shortcuts: **Space** = start/stop, **R** = reset.
